# 接线与操作

适用 HX4S20C / EG4S20BG256、ATK-MD0280 V2.4（ILI9341并口显示、XPT2046电阻触摸）。接口以本工程 pin.adc 为准。本整理版没有执行实板下载或Flash固化。

## 连接

HDMI连接支持音频的电视/显示器；TF卡使用 media 中的原始扇区镜像。LCD显示控制面板，媒体图像由HDMI显示。

### LCD与触摸接线


**所有表格均使用物理针号。LCD是2×17，开发板J2是2×20，不能按同号直接对接。** 用短杜邦线按信号逐根连接，建议约10～15cm；两端公针时用母对母。针脚间距购买前以实物测量或厂家机械图确认。

先根据《HX4S20开发板手册-HDL版2410》第7页的连接器缺口、1脚标记确定J2方向；可查看 开发板手册第7页。GPIO编号、FPGA封装管脚和连接器针号是三个不同概念。例如GPIOB_22是J2第25针，对应FPGA H5。

这份触摸版bit的引脚已由工程中的 `pin.adc` 固定，必须按下表接线。若改用别的GPIO，需要同时修改引脚约束、重新编译生成bit，再更新接线表；不能只移动杜邦线。

用户最新实物照片已确认：背面文字正向、排针位于下方时，左端靠板内的一排 `CS` 是第1脚，靠板边的一排 `RS` 是第2脚；向右依次奇数／偶数递增，最右侧 `TCS`／`CLK` 分别为33／34脚。不要用屏幕正面视角套用这个左右方向。实物丝印第6～21脚为D0～D15，与V2.4原理图一致；商品截图的数据线标签有跳号，应以实物及本表为准。

## 上电与校准

1. 插入已写入配套镜像的TF卡，连接HDMI和LCD，SW1、SW2先置图片/关闭测试音。
2. 在TD Programmer选择对应版本的.bit，先进行JTAG SRAM下载：复现交接版本选firmware/seed20_板测版本/hdmi_multimedia_touch_reset.bit；验证当前源码编译结果选td_project中的lab_ex5_i2s_v1.0.bit。
3. 依次点按并松开屏幕的三个十字：(32,48)、(288,48)、(32,176)。等待下一个十字后再点，完成三点校准。
4. 等待READY=1，再切图、轮播或调整参数。

## 操作

| 控件 | 作用 |
|---|---|
| PHOTO / VIDEO | 图片/视频模式切换 |
| NEXT / AUTO | 图片下一张/自动轮播开关 |
| PLAY / PAUSE | 视频继续/暂停 |
| MENU | HDMI参数菜单开关 |
| BRT − / ＋ | 亮度每次调整4，范围−64～64 |
| CNT − / ＋ | 对比度Q8为128、192、256、320、384，默认256 |
| RESET | 恢复亮度0、对比度256并重启媒体，保留触摸校准 |
| CAL | 重新执行触摸校准 |
| KEY1 (A2) | 整机复位，重新校准 |
| KEY2 (B2) | 下一张；菜单内减参数；菜单内长按退出 |
| KEY4 (C1) | 轮播；长按打开菜单；菜单内加参数/长按切选项 |
| KEY3 (B1) | 视频暂停/继续 |
| SW1 (C8) | 图片/视频切换；新变化与触摸选择按最后操作生效 |
| SW2 (C7) | HDMI测试音优先；正常视频原声时关闭 |

按钮稳定按下并释放后执行一次，拖出后释放取消，长按不连发。暂停时音频平滑静音，频谱逐步衰减，不能描述成所有显示量瞬时归零。

## 时间同步

通过板载CH340串口连接PC，用PowerShell运行（将COM3替换为实际端口）：

    .\scripts\sync_pc_time.ps1 -Port COM3 -Once

波特率115200、8N1。时间由PC校准，后续在FPGA中计时；不是掉电保持的RTC。

## 板测项目

检查四张图片、四种转场、异尺寸图片适配、字幕和时间、亮度/对比度与菜单、原声视频、暂停恢复、波形与16路Goertzel频谱、图片/视频往返、RESET与重新校准。再做冷启动和连续运行测试。SRAM下载掉电丢失，不能据此宣称Flash已固化。
